# 自定义根证书

用于配置当前机器专有的证书与私钥。当同时提供两个可读文件时，程序将使用该证书；否则只会创建当前进程临时证书，不再使用公开的固定密钥对。

## 配置键

- cert.file：用户证书文件路径（建议 PEM，亦可为常见 .cer/.crt）
- cert.key：用户私钥文件路径（建议 PEM）
- cert.name：证书名称（CN），用于系统证书库识别与安装；留空则使用 `wx_channels_download`

## 示例（config.yaml）

```yaml
cert:
  file: "C:/path/to/mycert.pem"
  key: "C:/path/to/mykey.pem"
  name: "MyProxyCA"
```

## 生效规则

- 同时配置且文件存在时，使用本机证书与私钥；否则仅使用进程级临时证书
- 临时证书不应安装到系统信任库；启用代理前请通过证书生成接口创建本机证书
- 路径建议使用绝对路径；相对路径请确保与程序工作目录一致

## 注意事项

- 证书与私钥必须匹配（同一对密钥/证书）
- 证书名称用于检测是否已安装并在系统证书库中识别、卸载
- Windows 安装/卸载证书涉及管理员权限；详见“根证书指南”
